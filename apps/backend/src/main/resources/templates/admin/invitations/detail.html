Invitation

An invitation is addressed to one person and redeems once: the address below is the only one it will register. Withdraw ends this invitation permanently; it does not affect any account already created from it, and there is nothing organization-wide to regenerate. The link itself is stored only as a hash and cannot be shown here or anywhere else — the organization’s own administrator invites the person again when a new one is needed.
