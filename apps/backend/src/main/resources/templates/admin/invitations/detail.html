Invitation

A Potriv invitation is an organization-wide join link, not a per-person invite: anyone holding the link can register while it is usable. Revoke disables this link permanently. Regenerate disables every active link for the organization and issues a fresh one. The link itself is never shown here — the organization retrieves it through its own invite endpoint.
